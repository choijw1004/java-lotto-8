## 프로젝트 개요
간단한 로또 발매기를 구현한다.

---

## 주요 기능

### 로또 구매
- 구매 금액 입력
- 구매 입력값 검증 (1,000원 단위)
- 구매 금액에 맞는 로또 발행 (1,0000 당 1장)
- 로또 번호 자동 생성 (1 ~ 45 중 중복 없는 6개의 번호)
- 발행된 로또 수량 출력
- 발행된 로또의 로또 번호 정렬하여 출력

### 당첨 번호 입력 
- 당첨 번호 6개 입력 (구분자 ",")
- 보너스 번호 1개 입력
- 당첨 번호: 6개, 1~45 범위, 중복 없음
- 보너스 번호: 1~45 범위, 당첨 번호와 중복 없음

### 당첨 결과 확인
- 각 로또와 당첨 번호 비교
- 일치 개수 확인
- 보너스 번호 일치 여부 확인 (5개 일치 시)
- 등수 판정

### 로또 통계 출력
- 등수별 로또 당첨 개수 (5등에서 1등으로 역순)
- 총 수익률 (둘쨰 자리에서 반올림)
    - 수익률 계산 
    `수익률(%) = (총 상금 / 구입 금액) * 100`

#### 로또 당첨 기준
| 등수 | 일치 개수 | 보너스 일치 | 상금 |
|------|----------|-----------|------|
| 1등 | 6개 |  | 2,000,000,000원 |
| 2등 | 5개 | O | 30,000,000원 |
| 3등 | 5개 |  | 1,500,000원 |
| 4등 | 4개 |  | 50,000원 |
| 5등 | 3개 |  | 5,000원 |

## 예외 처리

### 구입 금액 관련
- [x] 구매 금액이 숫자가 아닌 경우
- [x] 구매 금액이 1,000원 미만인 경우
- [x] 구매 금액이 1,000원 단위가 아닌 경우

### 로또 번호 입력 관련
- [x] 당첨 번호가 6개가 아닌 경우
- [x] 당첨 번호가 숫자가 아닌 경우
- [x] 당첨 번호가 1~45 범위를 벗어난 경우
- [x] 당첨 번호에 중복이 있는 경우

### 보너스 번호 입력 관련
- [x] 보너스 번호가 숫자가 아닌 경우
- [x] 보너스 번호가 1~45 범위를 벗어난 경우
- [x] 보너스 번호가 당첨 번호와 중복된 경우

## 기능 테스트

### 로또 구매 기능
- [x] 구매 금액을 입력받아 로또를 발행한다
- [x] 발행된 로또 수량을 출력한다
- [x] 각 로또 번호를 오름차순으로 정렬하여 출력한다

### 당첨 번호 입력 기능
- [x] 당첨 번호 6개를 쉼표(,)로 구분하여 입력받는다
- [x] 보너스 번호 1개를 입력받는다
- [x] 입력된 번호의 유효성을 검증한다

### 당첨 결과 확인 기능
- [x] 1등: 6개 일치 (2,000,000,000원)
- [x] 2등: 5개 일치 + 보너스 (30,000,000원)
- [x] 3등: 5개 일치 (1,500,000원)
- [x] 4등: 4개 일치 (50,000원)
- [x] 5등: 3개 일치 (5,000원)
- [x] 낙첨: 2개 이하 일치

### 통계 출력 기능
- [x] 등수별 당첨 개수를 5등부터 1등 순서로 출력한다
- [x] 총 수익률을 계산하여 출력한다
  - 수익률 = (총 상금 / 구입 금액) × 100
- [x] 수익률을 소수점 둘째 자리에서 반올림하여 출력한다

### 통합 테스트
- [x] 전체 프로세스가 정상적으로 동작한다
- [x] 여러 장의 로또가 각각 정확히 등수 판정된다
- [x] 정렬되지 않은 당첨 번호로도 정상 작동한다
- [x] 예외 발생 시 재입력이 가능하다
