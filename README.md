# java-lotto-precourse
## 구현할 기능 목록

### 로또 구매 기능
- 구매 금액을 입력 받는다.
- 구매 금액이 1,000원 단위인지 검증한다.
- 구매 금액만큼 로또를 발행한다. 
- 발행한 로또 수량과 번호를 출력한다.

### 로또 번호 생성 기능
- 1~45 사이의 중복되지 않는 숫자 6개를 생성한다.
- 생성된 로또 번호를 오름차순으로 정렬하여 출력한다.

### 당첨 번호 입력 기능
- 당첨 번호 6개와 보너스 번호 1개를 입력받는다.
- 당첨 번호가 6개인지 검증한다.
- 당첨 번호가 1~45 범위인지 검증한다. 
- 당첨 번호의 중복이 있는 지 검증한다.
- 보너스 번호가 1~45 범위인지 검증한다.
- 보너스 번호가 당첨 번호와 중복되지 않는지 검증한다.

### 당첨 결과 확인 기능
- 발행한 로또들의 번호와 당첨 번호가 몇 개 일치하는지 확인한다.
- 보너스 번호 일치 여부를 확인한다.
- 일치 개수와 보너스 일치 여부로 등수를 판단한다.

### 당첨 통계 출력 기능
- 등수별 당첨 개수를 집계한다.
- 각 등수의 당첨 개수를 출력한다.
- 총 수익률을 계산한다.
- 수익률을 소수점 둘째 자리에서 반올림하여 출력한다.

### 예외 
- 구매 금액이 숫자가 아닌 경우
- 구매 금액이 1,000원 미만인 경우
- 구매 금액이 1,000원 단위가 아닌 경우
- 당첨 번호가 6개가 아닌 경우
- 당첨 번호가 숫자가 아닌 경우
- 당첨 번호가 1~45 범위를 벗어난 경우
- 당첨 번호에 중복이 있는 경우
- 보너스 번호가 숫자가 아닌 경우
- 보너스 번호가 1~45 범위를 벗어난 경우
- 보너스 번호가 당첨 번호와 중복된 경우
- 예외 발생 시 "[ERROR]"로 시작하는 메시지 출력
- 예외 발생 시 해당 부분부터 재입력
